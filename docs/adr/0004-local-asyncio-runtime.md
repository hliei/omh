# 首版本地执行与 asyncio 边界

首版以内置 asyncio 为唯一异步运行时，只提供本地工具执行环境；文件工具操作宿主文件系统，bash 工具启动宿主子进程，应用显式提供工作目录等配置。工具通过 ExecutionEnv 接口工作，暂不实现容器、SSH 或远程沙箱适配，也不承诺 Trio / AnyIO 兼容。

首版支持 macOS 与 Linux，以 macOS 和 Ubuntu 24.04 x86_64 作为 SDK 与内置工具的 CI 验收环境；其他 Linux 发行版及架构不单独承诺已验证，Windows 不纳入首版。后续 SQLite 恢复、文件权限、bash 子进程与取消行为均需在两个平台通过相应测试。

2026-09-16 修订：为支持 Linux 服务器上的 SDK 使用，将原先仅 macOS 的范围扩展到 Linux；通过双平台 CI 持续验证兼容性。配置支持范围不等于已经完成 Linux 实测，验证结果以实际运行记录为准。

Python 以常规 CPython 3.14 构建作为首版验证基线，不承担旧版本、预发布版本或自由线程构建兼容；后续版本经验证再纳入支持。

这一选择将任务生命周期、调用取消与子进程管理限制在同一运行模型内，减少首版适配范围；保留执行环境接口以便以后接入实际需要的环境，不预先增加未知环境配置。asyncio 调用取消不得自动转化为持久化 operation 取消，相关语义遵循 [ADR-0002](0002-python-api-and-storage-boundaries.md)。
